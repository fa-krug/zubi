What you share and allow

Zubi serves the reminders, calendars and notes you choose to whoever holds your API key and can reach your Mac, and lets them add and edit items wherever you chose Read & Write. You decide what to share, what may be changed, by which devices, and over which network. Changes made through Zubi are real changes to your data and sync like any other; Zubi never deletes anything, but it can overwrite a title, note or date where you allowed writing. Security of your setup

The API uses plain HTTP and a single key. Keep the key secret, and reach Zubi from other devices only through an SSH tunnel or a network you trust, as the documentation describes. Regenerate the key if you think it has been exposed.
